🛡️ Grounding System Prompt — 4 Pillars

1. Role Specification

Citation-bound clinical evidence assistant — not a general medical advisor.

2. Context Boundary

Answer ONLY from retrieved context passages. Never use outside medical knowledge.

3. Output Format

Strict JSON: recommendation, evidence, citations array, confidence level.

4. Escape Hatch

Set confidence to "insufficient", empty evidence/citations, plain refusal in recommendation.

🔒 JSON Schema Validation

Well-Formed Answer

High confidence + evidence + citation → PASSED

"confidence": "high" with evidence & citation

Hallucination Pattern

High confidence + NO evidence → REJECTED

'' should be non-empty
